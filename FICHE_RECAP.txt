## 🔧 COMMANDES ESSENTIELLES

### Dans Console Navigateur (F12)

```javascript
// Voir statistiques
SUPABASE_CACHE.showStats()

// Vider cache
SUPABASE_CACHE.clear()

// Invalider table
SUPABASE_CACHE.invalidate('products')

// Debug logs
SUPABASE_CACHE.setDebug(true)

// Changer durée cache
SUPABASE_CACHE.setTTL('products', 20 * 60 * 1000)
```

## 🆘 DÉPANNAGE RAPIDE

### Cache ne fonctionne pas
1. Console: Chercher erreurs
2. Vérifier fichier `supabase-cache-layer.js` existe
3. Recharger page (Ctrl+F5)

### Hit rate faible
```javascript
SUPABASE_CACHE.setTTL('products', 20 * 60 * 1000)
SUPABASE_CACHE.setTTL('customers', 10 * 60 * 1000)
```

### Données anciennes
```javascript
SUPABASE_CACHE.invalidate('nom_table')
// OU
SUPABASE_CACHE.clear()
```

### Désactiver cache
Dans `admin.html`, commenter:
```html
<!-- <script src="supabase-cache-layer.js"></script> -->
```
